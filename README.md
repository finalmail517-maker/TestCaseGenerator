# AI Test Case Generator – Quick Start Guide

## Before You Begin

Make sure you have **Python 3.8 or higher** installed.

---

## Step 1 – Set Up Your API Credentials

Open the `.env` file in any text editor (Notepad is fine) and fill in your details:

```
LLM_API_KEY=paste_your_api_key_here
AZURE_OPENAI_ENDPOINT=paste_your_endpoint_here
AZURE_OPENAI_API_VERSION=paste_your_api_version_here
LLM_MODEL=paste_your_model_name_here
```

Save the file.

---

## Step 2 – Run the App

Double click **`setup_and_run.bat`**

Wait for it to finish — it will open the app automatically in your browser.

> First time may take a few minutes to install everything and to create virtual environment.

---

## Step 3 – Using the App

- Select test type from the **left sidebar**
- Paste a **GitHub URL**, upload a **code file**, or upload an **LLD .docx**
- Download results when done

---

## Something Not Working?

**App not opening** → Make sure Python is installed and `.env` is filled correctly.

**Any other error** → Take a screenshot of the error and contact the team.
